# Skill Repository

This repository is the canonical source for the user's local skills. Its current
path is `/home/pc/skills` (`~/skills`), not the nonexistent `/home/pc/skill`.

- For requested skill additions, modifications, renames, and deletions, maintain the corresponding repository skill and its installed copy under the active Codex home.
- Inspect both versions and Git status before syncing. Preserve unrelated user changes and resolve meaningful differences; do not blindly overwrite either version.
- For searches, inspections, and reviews, consult repository skills and compare installed versions where relevant. Read-only requests do not authorize synchronization.
- Resolve the repository mapping for system/plugin skills before changing them; ask when it is ambiguous.
- Sync only affected skill files and resources. Exclude generated caches and unrelated skills. Verify consistency and run applicable validation/tests.
- Before deletion, verify exact targets and prefer recoverable removal of both copies.
- Do not commit, push, or change remotes without a user request. Report the repository path and synchronization result.
